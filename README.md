# Portfólio — Adrian Pety

Portfólio pessoal criado com Next.js, React, TypeScript e Tailwind CSS.

## Executar localmente

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Estrutura

- `src/app`: página principal, layout e estilos globais.
- `src/components/sections`: seções do portfólio.
- `src/components/ui`: componentes reutilizáveis.
